# JAGAT Phase 1 Console

> **JAGAT Phase 1 Console — Operations, Mission Monitoring & Multi-Agent Revenue Ledger Interface**  
> Real-time monitoring and mission ledger control interface for the JAGAT sovereign multi-agent ecosystem.

👤 **Author**: Faturachman Alkahfi ([@Vinzz2303](https://github.com/Vinzz2303))

---

## ⚡ Tech Stack

- **Core**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Motion
- **Icons**: Lucide React
- **Server**: Express + Node.js (`server.ts`)

---

## 🚀 Development & Build

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
